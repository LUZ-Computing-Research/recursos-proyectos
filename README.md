# Recursos para Proyectos de Investigación (PTI)

Repositorio oficial de recursos, reglamentos, formatos, plantillas y guías para la elaboración de **Proyectos de Investigación (PTI)** del Departamento de Computación de la Facultad Experimental de Ciencias de la Universidad del Zulia (LUZ).

## Objetivo

Centralizar toda la documentación necesaria para que los estudiantes desarrollen y presenten su Proyecto de Investigación de manera organizada, siguiendo la normativa institucional vigente.

## Contenido de cada carpeta

### 📚 reglamentos

Documentos normativos y reglamentos institucionales que regulan el desarrollo y presentación del Proyecto de Investigación.

### 📄 formatos

Formatos administrativos requeridos durante las distintas etapas del proceso académico.

### 📝 templates

Plantillas editables que sirven como base para la elaboración de documentos académicos y presentaciones.

## Recomendaciones

- Utilice siempre la versión más reciente de los documentos publicados en este repositorio.
- No modifique los archivos originales; descargue una copia para su uso.
- Consulte periódicamente este repositorio para verificar actualizaciones.
